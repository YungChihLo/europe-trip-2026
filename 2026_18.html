GitHub Pages 免費上架

本網頁為單檔自包含設計（已內嵌全部 18 天行程 + 13 篇參考攻略 + 即時氣象 + 地圖連結）。點擊下方按鈕下載 index.html，上傳至 GitHub 即可生成專屬手機 APP 網址！

4 步驟免費變成手機隨身網站

1
建立 GitHub 儲存庫 (Repository)

登入 GitHub.com，點右上角 「+」➔「New repository」，輸入名稱（如 2026-europe-trip），設為 Public 並建立。

2
上傳 index.html 檔案

點選頁面上的 「uploading an existing file」，將剛剛下載的 index.html 拖曳放進去，點擊下方綠色 「Commit changes」。

3
啟用 GitHub Pages 託管

進入專案的 「Settings」➔ 左側「Pages」。在 Branch 下拉選單選 「main」 與 「/ (root)」，按 Save。

4
開啟網址並加入手機主畫面

約 1 分鐘後重新整理 Pages 頁面，即可看到專屬網址 https://您的帳號.github.io/2026-europe-trip/！用手機瀏覽器開啟後點「加入主畫面」，就能像原生 APP 隨時離線/線上查詢與一鍵地圖導航。
