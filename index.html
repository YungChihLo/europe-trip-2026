免費上架到 GitHub Pages

這是一個純靜態單檔網頁 APP（無需後端伺服器）。您可以直接點擊下方按鈕下載 index.html，並透過 GitHub 免費託管成專屬網址，加入手機主畫面就像原生 APP 一樣使用！

4 步驟完成網站上架教學

1
建立 GitHub 儲存庫 (Repository)

登入 GitHub.com，點擊右上角 「+」➔「New repository」。輸入名稱（例如 europe-trip-2026），設為 Public，點擊建立。

2
上傳 index.html 檔案

進入剛建立的儲存庫頁面，點擊 「uploading an existing file」，將剛剛下載的 index.html 拖曳上傳，然後點擊下方綠色按鈕 「Commit changes」。

3
開啟 GitHub Pages 網站服務

點擊上方選單 「Settings」➔ 左側「Pages」。在 Branch 下拉選單選擇 「main」 資料夾選 「/ (root)」，點擊 Save。

4
取得網址並加到手機桌面

等待約 1 分鐘重新整理 Pages 頁面，上方即會出現 https://您的帳號.github.io/europe-trip-2026/！用手機 Safari/Chrome 開啟並點選「加入主畫面」，即可隨時離線/線上查看與一鍵導航！
